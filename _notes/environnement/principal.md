# Environnement principal

L'environnement principal du cours tourne sur Debian 13 (Trixie) avec les composantes suivantes pré-installées: 

- **openssh-server**: serveur SSH
- **nginx**: serveur web
- **openssl**: librairie et outils de cryptographie
- **nmap**: balayage (*scan*) de ports
- **tcpdump**: capture et analyse de paquets réseau
- **curl**: requêtes HTTP
- **wget**: requêtes HTTP
- **vim**: éditeur de texte
- **nano**: éditeur de texte
- **rsync**: outil de synchronisation de fichiers souvent utilisé pour les sauvegardes et restauration
- **fail2ban**: complémentaire au cours; outil permettant de modifier le pare-feu dynamiquement
